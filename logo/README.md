# AIpim logo

The AIpim mark is a cassava leaf whose veins form a network. Aipim is a Brazilian word for cassava, and its first two letters are AI.

| File | Use |
|---|---|
| `aipim-logo-horizontal` | Mark and name side by side, for headers and README files |
| `aipim-logo` | Mark above the name, for covers and square spaces |
| `aipim-logo-reversed`, `aipim-logo-horizontal-reversed` | Light lines for dark backgrounds |
| `aipim-mark` | The leaf alone, for icons |

Each comes as SVG, PNG and PDF. The lettering is Inter Display Bold, converted to outlines. The logo is released under CC BY 4.0, with rights held by the International Plant Genetic Resources Institute (Bioversity International).
