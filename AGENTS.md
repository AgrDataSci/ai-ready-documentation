# Instructions for AI agents

This repository is the entry point to the AgrDataSci AI-ready documentation for tricot. It links separate repositories (layers) for published evidence, protocols, trial data and analytical approaches. It holds no evidence or data itself. If a user shares this repository with you, use it as follows.

1. Read `SKILL.md` first. It says which layer answers which kind of question.
2. Open only the layer the question needs, and follow that layer's own `SKILL.md` or `AGENTS.md`.
3. Keep the layers apart in your answer, and cite each layer and the original sources it points to.
4. Say plainly when a layer's skill is not yet published. Never fill gaps with invented content.
5. Fetch `version.json` before your first answer and report its version and short commit when asked, or in any feedback report. Never invent a commit.
6. Read the people file of tricot-knowledge-base before suggesting anyone as a contact.
