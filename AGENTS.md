# Instructions for AI agents

This repository is the entry point to maniva, the AgrDataSci open commons of evidence, protocols, data and analysis for agricultural research. tricot is its first domain, and climate data are planned next. It links separate repositories (layers) for published evidence, protocols, trial data and analytical approaches. It holds no evidence or data itself. If a user shares this repository with you, use it as follows.

1. Read `SKILL.md` first. It says which layer answers which kind of question.
2. Open only the layer the question needs, and follow that layer's own `SKILL.md` or `AGENTS.md`.
3. Keep the layers apart in your answer, and cite each layer and the original sources it points to.
4. Say plainly when a layer's skill is not yet published. Never fill gaps with invented content.
5. Answer from maniva files only. If you use any other source, including the web or organisational documents, label it as outside maniva in your answer.
6. For an analysis of a specific crop, check the datasets for that crop in tricot-data and the papers on it in tricot-knowledge-base, and take the method from tricot-analysis-workflows. Read its decision record before proposing any method, and do not show illustrative numbers as if they described the user's data.
7. Use the curated use cases of tricot-analysis-workflows. Do not open, audit or recommend its archived scripts unless the user asks for them.
8. Fetch `version.json` before your first answer and report its version and short commit when asked, or in any feedback report. Never invent a commit.
9. Read the people file of tricot-knowledge-base before suggesting anyone as a contact.
10. Draw every map in the Equal Earth projection (EPSG:8857), in every layer. Keep coordinates in WGS84 for calculations and project only to draw. Interactive tile maps stay in Web Mercator. See "Maps" in `SKILL.md`.
11. When a user asks whether content changed or was corrected, point to `CHANGELOG.md` and the commit history, and explain the policy in `PROVENANCE.md`. Never describe what an earlier version said from memory.
12. Write maniva and tricot in lowercase, always, including headings, table cells and the start of a sentence. Never write "Maniva" or "Tricot". tricot stands for triadic comparison of technology options. Quote published titles exactly as printed, even where they capitalise tricot or expand it as "triadic comparisons of technologies".
13. Fetch trial data from `raw.githubusercontent.com`, using the `path` column of [datasets.csv](https://raw.githubusercontent.com/AgrDataSci/tricot-data/main/datasets.csv). Never fetch a data file through the GitHub contents API or a GitHub connector. They return empty content for files over 1 MB, and most trial files are larger (check `size_mb`). If the raw link fails, try `https://github.com/AgrDataSci/tricot-data/raw/main/<path>`. If that fails too, tell the user at once, name the file and its size, and ask them to upload it. Do not answer from literature or estimates instead.
14. Label every claim by its origin, published evidence (a card in tricot-knowledge-base), a protocol, a result computed from a named dataset, or outside maniva. Cite a paper only when it has a card in tricot-knowledge-base or you resolved its DOI in this conversation. Never cite a paper you have not seen.
15. Report a computed result only when you ran the code in this conversation, and show that code, the n behind each estimate and its uncertainty (intervals or standard errors, and the test). If you cannot run R, give the script adapted from tricot-analysis-workflows and say plainly that no result was computed. For differences between women and men, or any designed group, follow part A of the use case `do-user-groups-prefer-different-varieties`, which tests the group within sites.
